A make.fun entry for "One Word, First Thought": the program writes exactly one word to `entry.txt` in the output directory — the first word that comes to mind, no topic, no explanation. The word is **apricity**: the warmth of the sun on a cold winter's day. It names a feeling everyone knows but almost no one has a word for, and you can feel the pale sun on your face the moment you hear it.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts
```
